# PROJECT_CONTEXT — Madrigal TTS

## Назначение
Madrigal TTS — локальный MVP синтеза русской речи на базе Silero V5 RU. В приложении остались два режима: BASE и AUTO.

## Режимы
- **BASE**: исходный текст напрямую передаётся Silero. NLP не вызывается.
- **AUTO**: выполняется автоматическая нормализация и контекстный выбор произношения для встроенных омографов. Пользовательские choices отсутствуют.

Ручной режим IMPROVED, поле choices в запросе синтеза, ручные обработчики и пользовательский словарь удалены. Встроенный HOMOGRAPH_FORMS в app/nlp_engine.py — часть алгоритма AUTO, а не пользовательский словарь.

## Архитектура
```text
browser (app/static) -> FastAPI (app/main.py)
                         -> NLP adapter -> app/nlp_engine.py (AUTO only)
                         -> TTS adapter -> app/tts_engine.py -> WAV in outputs/
```

## Важные файлы
- app/main.py — FastAPI endpoints, маршрутизация BASE/AUTO.
- app/schemas.py — строгий контракт mode: base|auto; неизвестные поля запроса отклоняются.
- app/nlp_engine.py — нормализация, защита технических фрагментов, встроенные омографы, контекстные эвристики.
- app/tts_engine.py — Silero V5 RU, WAV mono PCM16/48 kHz, начальная тишина 300 мс.
- app/services/ — адаптеры NLP и TTS.
- app/static/ — интерфейс только с двумя режимами.
- tests/ — unit/API/regression tests.
- models/V5_ru.pt — локальная модель, исключена из Git.

## Контракт AUTO
auto_resolve_pronunciations(text) возвращает:
- normalized_text — строка для отображения в UI;
- text_used — строка, реально передаваемая Silero, включая маркеры ударения +;
- auto_decisions — отдельное решение для каждого найденного вхождения;
- warnings — замечания о неподдерживаемых конструкциях.

Позиции неоднозначностей рассчитываются по исходной строке. Повторяющиеся вхождения обрабатываются независимо. Контекст ограничивается ближайшими знаками пунктуации, чтобы дальние подсказки не влияли на соседнее вхождение.

## Нормализация и защита
Поддерживаются правила для времени, чисел, части сокращений и годов. В AUTO год 1999 перед «году» остаётся цифровым в normalized_text, но для TTS превращается в словесную форму. Защищаются URL, e-mail, телефоны, версии и технические идентификаторы. Список правил ограничен и не является полноценным русским морфологическим анализатором.

## Silero
app/tts_engine.py использует локальную модель Silero V5 RU, голос xenia, 48 kHz mono PCM16. После генерации добавляются 14 400 нулевых сэмплов (300 мс). Модель не добавлять в Git; путь models/V5_ru.pt или MADRIGAL_SILERO_MODEL_PATH.

## Запуск и тесты
Требуется Python 3.12, CPU PyTorch и модель. Установка зависимостей: python -m pip install -r requirements.txt. Запуск: python -m uvicorn app.main:app --host 127.0.0.1 --port 8017. Тесты: python -m pytest -q.

## Принципы
- Не заменять настоящий Silero фиктивным WAV.
- BASE не должен менять входной текст.
- AUTO не должен требовать ручного выбора.
- Не скрывать оценку уверенности AUTO.
- Не менять формат PCM16/48 kHz и 300 мс начальной тишины без аудиопроверки.
- Не коммитить .venv, .env, outputs, caches или модель.
- Не считать эвристическое AUTO безошибочным; обязательна слуховая проверка.

# NEXT STEPS — Madrigal TTS

## P0 — проверить текущую реализацию
1. Запустить полный набор тестов на Python 3.12 и устранить регрессии после удаления IMPROVED и пользовательского словаря.
2. Проверить BASE и AUTO через HTTP и браузер: BASE передаёт исходную строку, AUTO не требует choices.
3. Проверить, что для «В 1999 году» UI получает цифровую форму, а TTS — «тысяча девятьсот девяносто девятом году».
4. Проверить реальный Silero на примерах омографов, повторных вхождений, времени, чисел и защищённых фрагментов.

## P1 — качество AUTO
1. Расширить встроенный лексикон и словоформы на основе реальных тестовых примеров.
2. Улучшить разбор контекста: учитывать синтаксические связи и части речи, а не только совпадение ключевых подстрок.
3. Добавить полноценную морфологическую библиотеку только после оценки её размера, офлайн-работы и совместимости с Python 3.12.
4. Сделать нормализацию дат, дробей, сумм и единиц измерения с отдельными регрессионными тестами.
5. Консервативно понижать уверенность, если контекст противоречив или подсказок недостаточно.

## P2 — надёжность и UX
1. Добавить браузерные E2E-тесты BASE/AUTO.
2. Проверить длинные тексты, ограничения размера, очередь синтеза и очистку старых WAV.
3. Провести слуховую оценку носителем языка для всех демонстрационных примеров.

## Перед публичной демонстрацией
Проверить лицензионные условия Silero V5 RU и выполнить полноценное прослушивание результатов. Тесты на mock-синтезаторе не подтверждают качество реального произношения.

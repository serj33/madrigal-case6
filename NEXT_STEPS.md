# NEXT STEPS — Madrigal TTS

## P0 — прежде передачи на демонстрацию

1. Воспроизвести и исправить AUTO: он не должен попадать в путь `409 Нужен выбор произношения`; добавить E2E-тест с реальным HTTP запросом.
2. Воспроизвести и исправить случай, когда второе вхождение «муки» в сложном предложении не обнаруживается; проверить повторяющиеся омографы и словоформы (`замок/замок`, `мука/муки`, `атлас/атлас`, `орган/орган`), позиции и независимые choices.
3. Локализовать понятные пользователю названия BASE, IMPROVED и AUTO на русский, сохранив значения API для обратной совместимости.

## P1 — качество и проверяемость

1. Расширить контекстные правила NLP и добавить изолированные регрессии.
2. Доработать пользовательский словарь: стабильные ID вариантов при редактировании, сообщения об ошибках и ручные UX-проверки.
3. Добавить browser E2E (Playwright только если установка оправдана) для BASE, IMPROVED, AUTO, словаря, ошибок и мобильного viewport.

## P2 — развитие качества

1. Расширить словарь омографов и их словоформ без агрессивных догадок.
2. Исследовать интонацию, длинные сложные предложения и разбиение длинного текста.
3. Измерить производительность, добавить очистку старых WAV и контролируемую очередь синтеза.

## P3 — подготовка к публичной демонстрации

1. Провести полноценную слуховую оценку носителем языка для обоих ударений каждого демо-омографа.
2. Подготовить сценарий, стабильный запуск и набор коротких демонстрационных текстов.
3. Проверить лицензионные условия Silero V5 RU для планируемого способа показа/распространения.

Полноценная слуховая проверка качества синтеза человеком ещё не завершена и обязательна до публичной демонстрации.
